# Frontend - Intelligent Academic Advisor

This is the frontend part of the project, built using **React + TypeScript + Vite**.

## 🛠️ Tech Stack

- React 18
- TypeScript
- Vite
- React Router DOM
- Chakra UI (for styling)
- Axios (for API calls)

## 🚀 Setup Instructions
cd frontend
npm install
npm run dev

## 📁 Project Structure
frontend/
├── src/
│   ├── pages/          # Main page components
│   ├── components/     # Reusable UI elements
│   ├── services/       # API calls
│   ├── hooks/          # Custom hooks
│   └── App.tsx
├── public/
├── index.html
