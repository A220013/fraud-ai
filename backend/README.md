# 🧠 Intelligent Academic Advisor - Backend

This is the backend service for the **Intelligent Academic Advisor** project.  
It is built with **Node.js**, **Express**, and **TypeScript** to provide RESTful APIs supporting user authentication, AI-powered Q&A, and course data scraping and management.

---

## 📦 Tech Stack

- Node.js
- Express
- TypeScript
- dotenv
- cors
- ts-node-dev (development only)

---

## 🚀 Getting Started

### 1. Install dependencies
npm install

### 2. Start the development server
npm run dev

## The backend will run at http://localhost:5000.
