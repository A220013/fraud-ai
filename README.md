# Intelligent Academic Advisor

This is a capstone project for UNSW CITS, aiming to build an AI-powered academic advising system for prospective and current students.

## 🔧 Technologies

- **Frontend**: React + TypeScript (Vite)
- **Backend**: Node.js + Express + TypeScript
- **Database**: MongoDB Atlas
- **AI**: Integrated with LLM (e.g., OpenAI GPT API)
- **Collaboration**: GitHub, Jira, Notion

## 📁 Project Structure
intelligent-academic-advisor/
├── frontend/ # Frontend React app
├── backend/ # Backend Express server
├── data/ # Raw scraped academic data
└── README.md # Project overview


## 🚀 Getting Started

1. Clone this repository.
2. Set up `.env` files based on `.env.example`.
3. Run frontend and backend as instructed in their respective folders.

## 📦 Branch Strategy

- `main`: Production-ready code
- `dev`: Integration branch
- `feat/*`: Feature development
